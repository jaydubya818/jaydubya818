## Mission Control, in one line

```
Constitution → Mission → Specification → Plan → WorkOrder → Context
   → Execution → Independent Verification → PR → Human Acceptance → Learning
```

Every arrow is a gate. The principle underneath all of it:

> Agent or harness completion is not the same as verified success.

Humans keep consequential authority. Agents propose and execute. Deterministic
code validates, governs, and records lineage. Memory, observability, and
learning stay advisory — they never become hidden authority.
