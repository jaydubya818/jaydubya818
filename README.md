## 🏭 FDLC.ai — Factory Development Lifecycle

**The engineering discipline for designing, governing, operating, evaluating, and continuously improving AI software factories.**

[**FDLC.ai**](https://fdlc.ai) is the public home of the Factory Development Lifecycle, an engineering framework for building reliable, governed autonomous software delivery systems.

FDLC defines how an AI software factory should operate. **Mission Control implements those principles in a working software delivery system.**

### The Factory Development Lifecycle

**Define → Plan → Configure → Execute → Verify → Deliver → Observe → Improve**

FDLC brings together:

- **Agent orchestration:** Agents, execution harnesses, tools, and workflows.
- **Context engineering:** RAG, memory, retrieval, and knowledge systems.
- **Durable execution:** Long-running workflows, state, retries, and recovery.
- **Evaluation & verification:** Quality gates, regression detection, and independent validation.
- **Governance & observability:** Permissions, budgets, evidence, tracing, and operational controls.
- **Continuous improvement:** Learning from verified outcomes and production evidence.

> **Verified delivery, not merely generated code.**

## 🚀 Mission Control — Autonomous Software Factory

**A governed control plane for human-directed, agent-executed software delivery.**

[**Mission Control**](https://github.com/jaydubya818/MissionControl) coordinates autonomous coding agents, execution infrastructure, independent verification, and human approval to produce evidence-backed, review-ready pull requests.

**Mission → Plan → WorkOrder → Execution → Verification → Pull Request → Human Acceptance → Learning**

### Core Capabilities

- **Agent Orchestration & Durable Execution:** Provider-independent harnesses, persistent workers, lease-based execution, isolated Git worktrees, scoped tools, and bounded recovery.
- **AI Evaluation & Independent Verification:** Rubric-based evaluations, baseline comparisons, deterministic quality gates, and independently verified outcomes.
- **Platform Governance:** Versioned Factory configurations, policy enforcement, execution budgets, audit trails, and human approval boundaries.
- **Observability & Learning:** Execution tracing, evaluation datasets, Factory Memory, failure analysis, and evidence-driven improvement proposals.

### Architecture & Technology

**TypeScript · React · Convex · Hono · GitHub Apps · GitHub Actions · Playwright**

Built with **16 packages, 190+ test suites, automated CI/CD, and independent verification**.

**Demonstrated:** End-to-end governed delivery from approved engineering intent through agent execution, independent verification, real GitHub pull requests, and human acceptance.
